# Scope-Unlocking Questions

5-8 Qs per pitch. NOT 16 (GutReno over-fired). 1 of them = pricing lever.

## Universal Q stack (copy + edit per niche)

1. **Real photos coming, or source stock from Unsplash/Pexels?**
2. **Domain + hosting ready, or need help setting up?**
3. **Logo locked, or want me to design (text-only / monogram / full mark)?**
4. **Final copy from you, or want me to draft niche placeholder copy?**
5. **Booking / form provider — Calendly / Tally / Formspree / native?**

Plus 1 pricing-lever Q (changes fee):

6. **Bonus: blog/CMS section for SEO? (changes fee)**

## Per-niche overrides

### Wedding / Vow / Luxury event
1. Real engagement photos coming, or stock?
2. Booking — Calendly / Tally / HoneyBook / native?
3. Domain + hosting ready, or need help w/ Divi install?
4. Logo — text-only locked, or open to gold monogram/symbol?
5. Final copy from you, or want me to draft wedding-industry placeholder?

### Wellness DNA / pre-launch brand
1. Which variant feels closest? (V1 Helix / V2 Editorial / V3 Glass / V4 Magazine / V5 Aesop)
2. Brand name + logo (have, or part of scope)?
3. Email destination — Beehiiv / Mailchimp / ConvertKit?
4. Domain owned, or Vercel subdomain v1?
5. Copy — you write, or +$150 add-on?

### Medical / clinic / surgical
1. Squarespace (your initial ask) or stay on Vercel?
2. Email tool — Mailchimp / SQ native / ConvertKit?
3. Real headshots / clinical photos coming?
4. Real NMC PIN / license # / ICO reg for footer + schema?
5. Domain DNS access?
6. Booking — Calendly / Cal.com / native form?
7. Bonus: blog/resources section for SEO? (changes fee)

### Wellness coach + book funnel (WordPress brief)
1. Book title + Amazon ASIN — wire affiliate-safe redirect?
2. Quiz — how many Qs, single CTA or branching?
3. Stripe ready, or include in build?
4. Email tool — Mailchimp / ConvertKit / ActiveCampaign / GHL?
5. Programme = sales page only, or full course members area? (BIG scope diff)
6. Brand assets ready (logo/photos), or design fresh?
7. Domain + WP hosting live, or set up?

### UK healthcare consultancy
1. Real business name + tagline?
2. Real contact email, phone, address (for schema)?
3. Logo — have, or design new?
4. Headshots / clinical setting photos?
5. Domain — `.co.uk` + `.com` registered?
6. Booking — Calendly / Cal.com / plain form?
7. Real anonymised case studies to replace sample testimonials?
8. Bonus: blog/resources section for SEO? (changes fee)

### Luxury rental / event service
1. Pick package — LAUNCH $X / LAUNCH+ $Y / GROWTH $Z?
2. Domain + hosting login share?
3. Real product / venue photos coming?
4. Form backend — Formspree / Web3Forms / n8n?
5. WhatsApp business # for booking CTA?
6. SEO location pages — how many cities to target?

### Indie event / promo
1. Final event date + venue locked?
2. Ticket provider — Eventbrite / Stripe / direct?
3. Card / lineup locked?
4. Photos / logos coming?
5. Domain registered?
6. Pixels — FB / Google Ads needed?
7. Post-event plan — kill page, archive, or convert to next event?

### Trade / contractor (HVAC, plumbing, roofing)
1. License # + insurance details for footer + schema?
2. Service area — how many cities to wire (max 30 in service-area widget)?
3. Real before/after photos coming?
4. Lead-magnet PDF — you have, or want me to draft (e.g. "5-point checkup")?
5. Phone # for sticky mobile call bar (`tel:` link)?
6. Form → email or CRM (HighLevel / Zoho)?

## Pricing-lever Qs (always include 1)

- "Bonus: blog/CMS section for SEO? (changes fee)"
- "Phase 2 — full site (10-15 pages, blog, members area) flagged in your brief, want quote alongside?"
- "Want me to also wire email automation (Beehiiv / Mailchimp w/ welcome sequence)? Add-on."
- "SEO location pages — 3 / 5 / 10 cities? Each adds £X."

## Format rules

- Number them 1-5 (or 1-8 max)
- ONE per line, no nested sub-bullets
- Bonus Q labeled clearly "Bonus:" or "Optional:"
- Last line: "Reply with what you have — live on your domain inside the week."
- NO fee in this message. Fee comes after answers.
